### Normal Mapping
Normal mapping is a performant technique that allows us to add fine detail to objects without extra geometery. It works by using a normal map texture to pertube the normals across an objects surface, this is passed on through the rest of the lighting calculation to display as if there was actual changes in the geometery.

The original lighting system operated in the world space, however normal maps describe the surface in tangent space. Therefore, to implement normal mapping we first needed to construct the TBN (tangent, bitangent, normal) matrix to transform the normals from tangent space to world space. To do this we utilise the fact that the tangents are already provided for us and can be extracted from the models in `ModelLoader` like we already do for normals. I then followed the way normal data was passed through to all the way to the shaders and did the same for the tangents, modifying the `EntityRenderer` and `BaseLitEntityShader` files accordingly.

Because I modified the Entity Renderers to include a normal map slot, I also needed to create a default normal map texture. For this I copied the implementation of the `default_white_texture` and intialising it to `rbg(128, 128, 255)` in `TextureLoader.cpp`. I then made sure to include this everywhere that the Entity Renderers were called.

Finally I began work on the actual shader implementation for regular and animated entities. For the vertex shader, I used the Gram-Schmidt process to construct the TBN matrix from just the normal and tangent vector, making sure to do it after bone transformation in the animated entity shader. This is then passed to the fragment shader where we sample the normal map, then multiply it by the TBN matrix to transform the perturbed normals into world space. 

Passing the modified `ws_normal` vector into the original lighting calculation results in the lighting effect coming out as intended.
